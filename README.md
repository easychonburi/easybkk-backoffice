# Easy - Bubble Backoffice

ระบบบันทึกเวลาและคำนวณเงินเดือนสำหรับสาขาวังหินและสะพานใหม่ เน้นการใช้งานบนมือถือ ตัวอักษรใหญ่ และจัดการทุกอย่างจากหน้าเว็บโดยไม่ต้องแก้ Google Sheet โดยตรง

## ความสามารถ

- เข้าสู่ระบบด้วย PIN แยกพนักงานและผู้ดูแล
- บังคับตรวจ GPS ตอนเข้างานและออกงาน
- เพิ่มเวลาย้อนหลังเป็นช่วงวันที่ พร้อมเว้นวันหยุด
- เพิ่มกะงานได้ไม่จำกัด ตั้งชื่อและเวลาเอง พร้อมกำหนดกะประจำให้พนักงาน
- วันลา เงินเบิก OT รออนุมัติ และหักมาสาย
- คำนวณเงินเดือนรายเดือน ค่าแรงรายวัน และ OT รายชั่วโมง
- เพิ่ม/แก้ไขพนักงาน สาขา และกฎค่าแรงจากหน้าเว็บ
- แจ้งเตือน Telegram โดยเก็บ Bot Token ใน Script Properties

## เริ่มใช้งาน

1. สร้าง Google Sheet ใหม่สำหรับ Easy - Bubble
2. เปิด Extensions > Apps Script แล้ววาง `Code.gs` และ `appsscript.json`
3. รัน `setupSystem()` หนึ่งครั้งและอนุญาตสิทธิ์ ระบบจะสร้างแท็บทั้งหมด สองสาขา และ PIN แอดมินครั้งแรก
4. Deploy > New deployment > Web app
   - Execute as: Me
   - Who has access: Anyone
5. นำ URL ที่ได้ไปแทนค่าใน `config.js`
6. เปิดหน้าเว็บและเข้าสู่ระบบด้วย PIN แอดมิน จากนั้นเพิ่มพนักงานและตั้งพิกัดทั้งสองสาขา

## การเผยแพร่หน้าเว็บ

ไฟล์ `index.html`, `clock.html`, `admin.html`, `admin.js`, `styles.css` และ `config.js` เป็นเว็บแบบ Static สามารถใช้ GitHub Pages, Netlify หรือบริการ Static Hosting อื่นได้

## ข้อควรระวัง

- ห้ามใส่ Telegram Bot Token ลงใน `config.js`, GitHub หรือ Google Sheet
- หลังตั้งค่าครั้งแรก ควรเปลี่ยน PIN แอดมินจากหน้า “พนักงาน”
- ก่อนใช้งานจริงให้ตั้งพิกัดสาขาวังหินและสะพานใหม่จากหน้า “ตั้งค่า” โดยยืนอยู่ที่สาขาแล้วกด “ใช้ตำแหน่งปัจจุบัน”
