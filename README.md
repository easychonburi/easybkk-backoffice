# Easy - Bubble Backoffice · Firebase

Firebase migration ของระบบบันทึกเวลาและเงินเดือน Easy - Bubble สำหรับสาขาวังหินและสะพานใหม่

## สถานะ

branch นี้เป็นระบบทดสอบคู่ขนาน ระบบจริง Google Sheets + Apps Script ยังทำงานเหมือนเดิมจนกว่าจะตรวจข้อมูลและอนุมัติสลับระบบ

## สถาปัตยกรรม

- Firebase Hosting: หน้าเว็บเดิมและ PWA
- Cloud Run (Node.js 22, Bangkok): ตรวจ PIN, session, GPS, สิทธิ์ และคำนวณเงินเดือน
- Cloud Firestore: พนักงาน สาขา กะ เวลา วันลา เงินเบิก และรอบเงินเดือน
- Firestore Security Rules: ปิด direct client access ทุก collection
- Telegram Bot Token: เข้ารหัสก่อนบันทึก และไม่อยู่ใน GitHub

## ฟีเจอร์ที่ย้ายมาครบ

- PIN 4 หลักแยกพนักงาน/ผู้ดูแล และเปลี่ยน PIN จากหน้าเว็บ
- บังคับ GPS ตอนเข้า–ออกงาน รองรับหลายสาขา
- หน้าพนักงานแสดงประวัติล่าสุด 3 รายการ และอ่านเฉพาะข้อมูลของพนักงานคนนั้น
- หลายกะ ตั้งชื่อ เวลา grace period และกะประจำได้
- เพิ่มเวลาย้อนหลัง วันลา เงินเบิก ตรวจ OT และหักมาสาย
- รายละเอียดเงินเดือนรายคน แก้เวลา เพิ่ม/หักเงินหลายรายการ และบันทึกร่างก่อนจ่าย
- เงินประกันสะสมพร้อมประวัติ และเพิ่มยอดอัตโนมัติเมื่อยืนยันเงินเดือน
- สลิปเงินเดือนเป็นรูป PNG สำหรับบันทึกหรือแชร์ให้พนักงาน
- พนักงานเลือกเบิก 500/1,000 บาทหลังเข้างานวันอาทิตย์ หรือเลือกไม่เบิกได้
- ดูและคัดลอกเลขบัญชีพนักงาน
- ยืนยันจ่ายทีละคนและล็อกข้อมูลที่จ่ายแล้ว
- หน้าข้อมูลระบบแบบตารางสำหรับตรวจเวลา วันลา เงินเบิก เงินเดือน เงินประกัน และประวัติการเปลี่ยนแปลง
- อ่านข้อมูลแบบจำกัดตามพนักงาน วันที่ และเดือน พร้อมแบ่งหน้าข้อมูลระบบครั้งละ 50 รายการ
- ยกเลิกการยืนยันจ่ายรายคนอย่างปลอดภัย พร้อมคืนสถานะเงินเบิกและเงินประกันที่เชื่อมโยงกัน
- แจ้ง Telegram, loading state, mobile UI และ PWA
- วันและเวลาทั้งหมดคำนวณด้วย `Asia/Bangkok`

ดูขั้นตอนสร้างโปรเจกต์และย้ายข้อมูลที่ [FIREBASE_SETUP.md](FIREBASE_SETUP.md)

## อัปเดตระบบที่ Deploy แล้ว

บน Cloud Shell ให้ดึง branch นี้แล้วรัน `bash scripts/update-cloud-shell.sh` สคริปต์จะอัปเดต Cloud Run, Firestore Rules และ Hosting โดยไม่เปลี่ยน PIN, กุญแจเข้ารหัส, Telegram หรือข้อมูลเดิม
